Remote Pad 1.2.0 adds a portable Windows app and PlayStation 5 controls on both Mac and Windows. The Xbox and PS5 players turn keyboard and mouse input into controller buttons and stick movements. You can look around with both mouse buttons released and keep turning while aiming and firing.

**Downloads**

- [Mac, Intel and Apple silicon](https://github.com/lamacchiasolutions/remote-pad/releases/download/v1.2.0/Remote-Pad-macOS.zip) — unzip and move Remote Pad to Applications. Requires macOS 13 or later. The app uses an ad hoc signature and is not Apple-notarized.
- [Windows x64](https://github.com/lamacchiasolutions/remote-pad/releases/download/v1.2.0/Remote-Pad-Windows-x64.zip) — use **Extract All** and open **RemotePad.exe** from the extracted folder. Requires Windows 10 or 11, .NET Framework 4.8 and the Evergreen WebView2 Runtime. The executable is unsigned.

**Xbox:** Choose **Open Xbox Remote Play** and sign in with the Microsoft account linked to your console.

**PS5:** Start Docker Desktop, open **PS5 setup → Start PS5 Player**, then choose **Open PS5 Remote Play**. Pair a PS5 on your home network using the console's pairing code and the base64 PSN account ID. The launcher downloads a separate PS5 Web Play companion on first use. On Mac, PS5 audio requires Safari 26 or newer. [PS5 setup and pairing](https://github.com/lamacchiasolutions/remote-pad/blob/v1.2.0/docs/PS5.md)

Both apps include a PS5 controller model, touchpad click, editable stick directions and an offline input test. Shared controls use the same bindings across consoles. The Mac app and extracted Windows package have been exercised with input tests. These checks cover input capture, mouse look, simultaneous trigger presses, and release to neutral. Gameplay on a signed-in physical Xbox or PS5 has not been independently verified.
